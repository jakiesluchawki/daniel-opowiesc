## Redakcja i źródła

Podstawą rozszerzenia jest [pełne nagranie PJAIT](https://www.youtube.com/live/SurotppGtyA), 10:38:45, oraz [oficjalny program](https://aisummit.pja.edu.pl/program-konferencji-ai-summit-pjait/). Godziny programu nie są czasami wideo. Mapy są orientacyjne, ustalone z cue napisów. Nie użyto pozornych rozdziałów wyprowadzonych z harmonogramu opisu.

Nowe opracowania są parafrazami. Pominięto promocję, organizację i przerwy, również wewnątrz paneli. Dawne teksty użytkownika porównano z niezależnym rozpoznaniem czystego dźwięku streamu i jego automatycznymi polskimi napisami. To audyt rozpoznań, bez deklaracji ręcznego odsłuchu każdego słowa. Niezgodne odczyty pozostają oznaczone.

Opinie, przykłady i prognozy należą do rozmówców. Lista programu nie służy do identyfikowania niepewnych głosów. Wstęp Naskręckiego sprawdzono z transmisją: Lanzarote jest czytelne, nazwisko Houellebecqa nadal nie pada. Banach pozostaje parafrazą. Autoteliczność jest wyraźna w trzeciej części Q&A; wcześniejsze słowo dotyczy autyzmu. Nazwisko Jacoba z Anthropic nadal jest niepewne. Bibliografia nie zastępuje dowodu tego, co powiedziano.
